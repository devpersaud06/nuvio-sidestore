# Nuvio — SideStore source

Personal SideStore source for a modified build of [Nuvio](https://github.com/NuvioMedia/NuvioMobile)
(GPL-3.0) with Netflix-style automatic quality switching, a quality menu, fast start, scrub
previews and next-episode preloading.

## Add to SideStore

Sources → **+** → paste:

```
https://raw.githubusercontent.com/devpersaud06/nuvio-sidestore/main/source.json
```

Then install **Nuvio** from the source. It uses its own bundle ID
(`com.devpersaud.nuvio`), so it installs next to the official Nuvio instead of replacing it.
